# Datenstruktur

Jedes Wort soll langfristig zusätzliche Informationen besitzen.

Beispiel:

```json
{
  "id": "g6_u1_001",

  "grade": 6,

  "unit": "u1",

  "topic": "technology",

  "difficulty": 1,

  "de": "Kamera",

  "en": "camera"
}
```
